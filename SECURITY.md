# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately via GitHub Security Advisories on this
repository (Security tab, "Report a vulnerability"). Do not open public
issues for security reports.

Include what you found, affected version or commit, reproduction steps
and impact as you assess it.

## What to expect

- Acknowledgment within 48 hours.
- Assessment and severity triage within 7 days.
- Critical issues are fixed with priority; you will be credited in the
  release notes unless you prefer otherwise.

## Scope

The latest release and the main branch are in scope. Coordinated
disclosure is appreciated: please allow a fix to ship before publishing
details.
